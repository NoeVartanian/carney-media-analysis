# Mark Carney in the Media: Analysis of North American Coverage on Mark Carney

In this data science project, we aimed to answer the following question: "How is Mark Carney perceived in North American media since and leading up to his term as prime minister of Canada, in tone and topic, across the political spectrum?"

## Files
Scripts for articles extraction and tf-idf computation are inside ```scripts```.

Code for exploratory analyses and plots are inside ```analysis```.
